# 匈汉象棋

[查看规则](wiki/rules.md)：棋盘与初始摆法、十种棋子的走法和吃法、胜负与和棋规则，附图示说明。

## 开发

使用 Node.js 24 和 pnpm，根目录统一管理三个工作区：

- `core/`：棋盘、规则、棋谱、摆子校验与 bgio 游戏定义，供两端共用。
- `web/`：React 页面、皮肤、音效和浏览器存档。
- `server/`：最小 bgio 服务端入口。

```sh
pnpm install
pnpm dev          # 直接加载 core 源码，启动网页 http://127.0.0.1:5173
pnpm test         # core、web 和 server 的常规测试与联机集成测试
pnpm test:random  # 随机对局测试
pnpm build        # 按依赖顺序构建三个工作区
pnpm preview      # 预览 web/dist 的生产页面
pnpm dev:server   # 编译并监听 core，启动并监听服务端，默认端口 8000
```

服务端通过 `PORT` 和 `WEB_ORIGINS`（逗号分隔）配置监听端口及允许的网页来源；默认允许 `http://127.0.0.1:5173`。
生产环境先执行 `pnpm build`，再执行 `pnpm --filter @xionghan/server start`。
网页顶部的「联机对弈」可创建房间、选择红黑、分享链接或加入邀请；刷新房间链接会恢复当前浏览器保存的座位。本地对局存档与联机凭证分开保存。
开发时同时运行 `pnpm dev` 和 `pnpm dev:server`，网页通过 Vite 代理访问服务端，无需把 8000 端口写进邀请链接。可用另一浏览器或无痕窗口模拟对手。
生产环境将 `/games` 与 `/socket.io`（含 WebSocket）反向代理到服务端，其余请求托管 `web/dist`；若使用独立服务端域名，在构建网页前设置 `VITE_API_SERVER_URL`，并把网页来源加入 `WEB_ORIGINS`。

服务端使用 bgio 的 FlatFile 存储，数据默认保存在 `server/data/`，可通过 `DATA_DIR` 指定目录；正常停止时等待写入完成，重启后保留房间、座位和棋谱。当前仅支持单实例，不要让多个服务进程共用这个目录。尚未提供公开大厅列表和自动匹配。

公网服务默认限制：每个 IP 每分钟最多 120 次大厅 API 请求、每 10 分钟最多 5 次建房或重开请求（包含失败尝试），全服最多 500 个房间，并发创建也不能突破上限。WebSocket 必须凭有效座位连接，每个 IP 最多 20 条同时连接，每分钟最多 120 条客户端事件；同步不存在的房间不会自动建房。可用 `CREATE_RATE_LIMIT` 和 `MAX_ROOMS` 调整建房频率及容量。
过期房间每分钟扫描回收：无人入座 10 分钟，未凑齐且无人在线 15 分钟，双方离线 30 分钟，结束后无人在线 24 小时；任何一方在线时不回收。回收会删除该房间的座位、局面和棋谱，原邀请链接随后失效。
限流仅在连接来自受信任代理时读取 `X-Forwarded-For` 的最后一个地址。`TRUST_PROXY_IPS` 默认只信任本机回环地址；使用其他反向代理时应明确填入代理的连接 IP，并确保代理正确追加或重写转发头，避免把所有用户识别为同一 IP。

## 已实现

- **联机对弈**：建房、邀请加入、执黑翻转、断线重连、刷新恢复及服务端持久化；联机时复用现有棋盘、棋谱、皮肤和音效。

- **皮肤**：导入含 `skin.properties` 的 ZIP 皮肤包，按 ID 更新，支持切换、删除与刷新恢复；可单独替换棋盘、棋子、背景和棋盒，棋盒与棋谱支持单段点九图，缺少的资源继续使用默认绘制。

- **棋谱**：自动记录每步走法，支持查看起始局面、逐步浏览和返回最新局面，随对局一起保存；查看历史时暂停落子。

- **自动保存与恢复**：保存当前局面、行棋方、上一步、胜负状态、摆子草稿和音效开关，刷新或重新打开后自动恢复。
- **安装与离线使用**：支持安装到桌面或主屏幕；首次联网加载后，可离线对弈和摆子，字体与音效一并缓存；发现新版本时提示更新，由用户确认后激活并刷新。
- **默认棋盘**：13×13 棋盘，双方各 22 枚棋子，按默认布局开局。
- **同屏双人对弈**：红方先行，双方轮流走棋；点选己方棋子后，点击合法落点移动或吃子。
- **十种棋子规则**：包含马的日字与直三、兵过长城、锐沿斜轨行走、卫在空心点间横行，以及檑的特殊吃子限制。
- **合法性检查**：校验棋子归属、移动路径、阻挡和吃子条件，禁止两王照面及使己方王受到攻击的走法。
- **局面提示**：显示选中棋子、合法落点、可吃目标、上一步位置、当前行棋方和将军状态。
- **胜负判定与新局**：将死或困毙时判负；可重新开局，已有走子时需确认。
- **键盘操作**：方向键移动棋盘焦点，Enter 或空格选子、落子，Escape 取消选择。
- **音效开关**：选子、走棋、吃子、将军和胜负音效，默认开启，可在页面顶部随时切换。
- **摆子模式**：编辑当前局面、补子和移除棋子，可清空非王棋子或恢复默认布局；校验通过后从摆好的局面开始对弈，也可取消并返回原对局。
