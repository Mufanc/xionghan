# 匈汉象棋

基于 13×13 棋盘、十种棋子规则的象棋游戏，双方各 22 枚棋子。支持同屏双人、人机对战、联机对弈和摆子，可安装为 PWA 并离线游玩本地模式。

[游戏规则](wiki/rules.md) · [联机服务部署](server/README.md) · [皮肤包规范](wiki/skins.md)

## 本地运行

需要 Node.js 24 和 pnpm。在项目根目录执行：

```sh
pnpm install
pnpm dev
```

打开 <http://127.0.0.1:5173> 即可使用本地模式。开发服务器直接加载 `core` 源码。

调试联机时，在另一个终端执行：

```sh
pnpm dev:server
```

服务端默认监听 8000 端口，Vite 会代理 API 和 WebSocket 请求，无需把 8000 端口写进邀请链接。可用另一浏览器或无痕窗口模拟对手。开发模式不限制 Origin，生产部署请参照[部署说明](server/README.md)。

## 功能与操作

- **同屏对弈**：红方先行，点选己方棋子后移动或吃子。支持合法走法、上一步与将军提示；禁止两王照面或使己方王受攻击，将死或困毙时判负。
- **人机对战**：顶部「人机」选择执红或执黑，Rust AB 引擎通过 WASM 在 Worker 中运行，每步思考约 3 秒。支持刷新恢复，切换模式会确认开启新局。
- **联机对弈**：创建房间、选择红黑、分享邀请链接；支持执黑翻转、断线重连、刷新恢复、双方同意的悔棋、求和与认输。大厅「我的对局」可恢复尚未回收的对局或复盘已结束对局。
- **摆子**：编辑棋子、清空非王棋子或恢复默认布局；校验通过后从当前摆法开局，也可取消并返回原对局。
- **棋谱**：自动记录走法，支持从起始局面逐步复盘、返回最新局面，以及 JSON 文件导入导出。复盘时暂停落子。
- **皮肤与音效**：导入 ZIP 皮肤包，替换棋盘、棋子、背景和面板，支持切换、删除与刷新恢复。音效默认开启，可在顶部关闭。
- **自动保存与离线**：保存局面、行棋方、上一步、胜负、摆子草稿和音效开关。首次联网加载后可离线对弈、摆子及使用人机；字体、音效和 WASM 一并缓存。新版本由用户确认后激活并刷新。

键盘操作：方向键移动棋盘焦点，Enter 或空格选子、落子，Escape 取消选择。完整走法与胜负规则见[游戏规则](wiki/rules.md)。

### 棋谱文件

对局菜单支持「导出棋谱」；本地模式还支持「导入棋谱」。导出为带版本号的匈汉象棋 JSON 文件，包含初始局面、完整走棋记录和当前轮次，不包含联机座位凭据或浏览器偏好。导入校验通过后仍需确认，确认才替换当前本地对局，并从起始局面打开复盘；回到最新局面可以继续本地对弈。

目前只支持本项目导出的 `xionghan-record` v1 格式，文件上限 10 MB、20000 手。导出的文件保存在用户本地，不受服务端房间回收影响。

### 联机身份与存档

本地对局存档与联机凭证分开保存。联机使用浏览器的匿名身份 Cookie，大厅列出该身份尚未回收的房间；复盘联机棋谱不覆盖本地对局。

清除 Cookie 或更换浏览器后，无法仅凭房间号认领原身份的座位。服务端房间会定期回收，已结束对局保留 24 小时；需要长期保存时请导出棋谱。身份、旧版凭证迁移与回收规则见[部署说明](server/README.md)。

### WebMCP

支持 WebMCP 的浏览器在人机模式下可调用 `xionghan_get_position` 读取局面与合法走法，再用返回的 `positionId`、`from`、`to` 调用 `xionghan_move` 代玩家走棋。电脑回合、复盘、摆子和结束后禁止落子；退出人机模式时移除入口。不支持 WebMCP 的浏览器仍可正常手动对弈。

### 自定义皮肤

导入含 `skin.properties` 的 ZIP 文件，同 ID 再次导入会更新皮肤，缺少的资源使用默认绘制。棋谱、联机操作区、菜单、弹窗、棋盒与大厅卡片共用面板样式。文件名、点九图和配色字段见[皮肤包规范](wiki/skins.md)。

## 开发与验证

| 命令                | 用途                                     |
| ------------------- | ---------------------------------------- |
| `pnpm dev`          | 启动网页开发服务器                       |
| `pnpm dev:server`   | 编译并监听 core，启动并监听联机服务      |
| `pnpm test`         | core、web、server 常规测试与联机集成测试 |
| `pnpm test:random`  | 随机对局测试                             |
| `pnpm build`        | 按依赖顺序构建三个工作区                 |
| `pnpm preview`      | 预览 `web/dist` 的生产页面               |
| `pnpm format:check` | 检查格式                                 |

项目由三个工作区组成：

- `core/`：棋盘、规则、棋谱、摆子校验与 bgio 游戏定义，供两端共用。
- `web/`：React 页面、皮肤、音效和浏览器存档。
- `server/`：bgio 联机服务、匿名身份和房间存储。
